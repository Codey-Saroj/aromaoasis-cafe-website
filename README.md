# AromaOasis Café ☕🌿  
Live Demo: [Visit Website](https://codey-saroj.github.io/aromaoasis-cafe-website/)

Welcome to the official repository for **AromaOasis Café**, a beautifully designed cafe website built using **HTML and CSS**. This project showcases a modern, responsive layout suitable for a local cafe, coffee shop, or restaurant, offering users a delightful browsing experience.

---

## 🌟 Features

- 🖼️ Eye-catching homepage design  
- 📜 Well-structured menu section  
- 🕒 Opening hours and contact information  
- 📱 Responsive design for mobile and desktop  
- 🔗 Smooth navigation links  

---

## 🛠️ Built With

- **HTML5** – For structure and layout  
- **CSS3** – For styling and responsive design  
- *(No frameworks used – purely handcrafted)*
